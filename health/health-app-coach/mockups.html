Technical Foundation
Built to scale, built for privacy
Mobile
Swift iOS
Native HealthKit access (required). Terra SDK wraps Garmin, Oura, and Strava into one normalized webhook.
Backend
FastAPI + TimescaleDB
Python async API. TimescaleDB for time-series metrics. PostgreSQL compatibility for complex cross-signal queries.
AI Coaching
Claude API
200K context window. Prompt caching keeps AI cost at ~€0.50/user/month. Context = 7-day metrics + biomarkers + event log.
Data & Privacy
EU Servers
All health data on AWS Frankfurt or Azure Switzerland. GDPR + Swiss nDSG compliant from day one. Encrypted at rest and in transit.
